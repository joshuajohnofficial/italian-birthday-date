# A table for two — Teresa’s invitation

Open index.html in your browser to preview. Keep all four website files together.

## Publish on GitHub Pages

1. Sign in to GitHub and create a new public repository, for example `teresa-date`.
2. Choose **Add file → Upload files**. Upload `index.html`, `style.css`, `script.js`, and `sad.gif` directly to the repository (not inside another folder), then commit the files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and **/(root)** folder, then click **Save**.
6. Wait for GitHub to display the published URL. It will usually look like `https://YOUR-USERNAME.github.io/teresa-date/`.
7. Open that link and try the invitation before sharing it with Teresa.

## Included

- Cream and cherry-red Italian dinner design.
- No opens “Just say that you hate me” with an original animated sad-heart GIF.
- After 1.5 seconds, Yes follows a desktop mouse pointer. Keyboard users and reduced-motion visitors retain a stationary button; touch devices keep normal buttons.
- Catch seven hearts by tapping or clicking. Each heart is catchable for 0.7 seconds, then disappears for 0.15 seconds before appearing at a different position. Missed hearts do not reduce your score.
- Winning reveals Pomodoro, 8:00 PM, 3 Nov 2026, and “Wear something stunning (more than your usual)”.
- No accounts, tracking, external assets, or installation required.

The invitation does not send an RSVP notification. All interactions happen in the visitor’s browser.
